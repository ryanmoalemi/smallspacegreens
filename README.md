# Small Space Greens

Static how-to site for small-space gardening and microgreens, published at [smallspacegreens.com](https://smallspacegreens.com/).

Pages are plain HTML, CSS, and one client-side calculator. `scripts/build_site.py` regenerates them from `src/`. The built files are what GitHub Pages serves from the repository root.

```bash
python3 scripts/build_site.py
```
