# Fortune Lab chart engine

Browser ESM adapter for the real MIT-licensed chart calculator in [Renhuai123/ziwei-doushu](https://github.com/Renhuai123/ziwei-doushu), pinned at `39c0abd3b8dac609975dddfadd4d4e1d3a978deb` (2026-11-21).

## Deliverable

Run the build commands below to create `dist/`, then copy its contents into the demo's assets directory. Keep `THIRD_PARTY_LICENSES.txt`, `LICENSE-ziwei-doushu.txt` and the generated `.LEGAL.txt` with the bundle.

```js
import { generateProfile } from './chart-engine.js';
const result = generateProfile({
  date: '1990-06-15',
  time: '14:30',
  gender: 'female'
});
// result.mode === 'ziwei'
// result.starKey === 'jumen'
// result.archetype === 'The Truth-Seeker'
// result.chart.palaces contains all 12 computed palaces.
```

`time` uses 24-hour `HH:mm`. The traditional chart setting must be `male` or `female`; this is an input to the source algorithm. `clockTime` is an alias. Advanced callers may supply `hourBranch` as an integer 0–11 instead, using an already-adjusted Gregorian chart date. Prefer `time` in the visitor flow to avoid ambiguity around 23:00.

```js
generateProfile({date:'1990-06-15', unknownTime:true});
// mode === 'numerology', lifePath === 4, chart === null
```

No input leaves the browser. There are no API keys, network calls, accounts or backend services in this bundle. The source engine contains a current-age field derived from the runtime date; natal star positions remain deterministic for the same inputs and conventions.

## Output fields

- `mode`: `ziwei` with a known time, or `numerology` without one.
- `starKey`, `star`, `archetype`, `traits`, `reflection`, `practice`: original English editorial labels/prompts tied to the first Life Palace major star. If the Life Palace is empty, the output explicitly identifies its use of opposite-palace stars.
- `lifePalace`: branch, actual `majorStars`, `borrowedStars`, `isEmpty`, and `borrowedFromBranch`.
- `chart`: unabridged 12-palace calculated chart from the upstream engine. Null for numerology.
- `calculation`: input and adjusted date, hour branch, late-Zi rollover, conventions and primary-star source.
- `lifePath`: numerology number calculated from the Gregorian date, available in either mode.
- `methodology`: human-readable method description.

## Honest scope and conventions

This is a functioning traditional chart calculator, not a scientific prediction system. The English prompts are newly written symbolic reflection content. They are not generated by an LLM at request time and do not come from the upstream interpretation dataset or lecture transcript corpus.

The adapter uses entered **local clock time** without automatic daylight-saving, historical timezone, longitude or true-solar-time correction. The UI should disclose this, especially for births near two-hour boundaries. A future production version can gather birthplace/timezone and explicitly implement those corrections.

The chart follows the upstream split leap-month convention and QS brightness tables. 23:00–23:59 rolls to the next Gregorian chart day; 00:00–00:59 stays on the entered date. Input date validation supports 1900–2099 and rejects impossible Gregorian dates. The frontend should additionally prevent future birth dates if collecting actual birth information.

The numerology fallback sums every digit of the Gregorian birth date, then reduces while retaining 11, 22 or 33 when reached. It is clearly labeled as a symbolic number exercise. It does not substitute a guessed birth time into the astrology engine.

## Dependencies and rights

Runtime dependencies are pinned to the versions in the upstream lockfile: `iztro@2.6.1`, `lunar-javascript@1.7.7`. Their dependencies are bundled for offline operation. `esbuild@0.25.12` builds the browser bundle.

Six MIT core files are copied without semantic modifications from upstream: `algorithm.ts`, `constants.ts`, `school-data.ts`, `school-tables.generated.ts`, `school-config.ts`, `types.ts`. `src/index.ts` is the original adapter and English editorial content. No noncommercial lecture quotations or 56.6 GB interpretation data are used in the browser application.

A separate complete upstream source snapshot was preserved privately for later project research. It includes mixed-license repository materials and is deliberately excluded from this maintainable engine directory. This directory contains only the six MIT chart files, the original adapter, build instructions, tests, and required notices.

## Rebuild and verify

```
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm test
```

Tests cover the pinned reference chart, missing birth time, impossible dates, leap dates, time/gender/branch validation, 23:00 rollover, the 01:00 branch boundary, all 12 branch settings for both chart genders, empty-palace attribution and the numerology method.
